What running this found

The first pass through this bank surfaced a genuine bug, not a model-quality ceiling — worth walking through because it's the main reason the score moved.

Multi-lender detection was silently dropping a lender from comparison questions

Lender detection ran in tiers: check every lender's canonical name first, and only fall through to product/brand-name matching (like flexicommercial, metroeco) if no lender matched canonically. That gating was fine for single-lender questions, but for a two-lender comparison it meant: if one lender was named canonically ("Angle") and the other only by product name ("flexicommercial" — which never matches FLEXI's canonical "flexi" keyword, since it's one unbroken word with no word-boundary break), the function returned only the canonical match and never even checked the second lender's product-name tier. FlexiCommercial vanished from retrieval entirely on exactly this pattern.

This one bug explained why "Cross-lender comparison (2)" was the single worst-scoring category — the model wasn't reasoning badly, it was answering with half the panel invisible to it.

A note on how confident to be in these exact numbers

Grading methodology and its limits

Each answer was scored 1–4 by gpt-4o — deliberately a different model from the gpt-5 answerer, so it isn't marking its own work — given the question, the fixed rubric, the gold-standard reference answer, and the specific trap the question was designed to test. The rationale for every score is kept alongside it for spot-checking.

  • gpt-5 has no temperature parameter, so re-running the identical question with identical retrieved chunks can still produce a differently-worded answer. Comparing the two full runs done today: 24 of 111 questions got a different score on re-grading despite retrieving the exact same source chunks both times — that's pure answer-phrasing / grader-judgment noise, not a real change in correctness. Only 22 questions had retrieval genuinely change (the ones the fix above affected).
  • Treat the per-question scores as indicative, not exact — a single question's 3-vs-4 grade can flip on a re-run. The category averages and the overall 3.31 → 3.41 shift are the more reliable signal, since they're computed over enough questions to average out that noise.
  • The raw transcript (ComplexQuestions_Answers.txt) is kept specifically so any of these grades can be checked by eye rather than taken on faith.
