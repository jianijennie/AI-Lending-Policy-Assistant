Why the projection stops at +10 points, not higher: the honest, defensible number only counts questions actually re-tested against the live backend. Several other questions in the baseline's low-scorer list sit in categories these fixes plausibly help — CQ-043 (Cross-lender + multi-filter, all-lender ranking) looks like the same shape of question the fan-out classifier fixed; CQ-014 and CQ-107 (Multi-filter, Angle/CFAL) weren't touched by any of today's six changes as far as directly verified. Assuming they're also fixed without checking is exactly the kind of claim this project's own testing discipline this session was built to avoid — better to report 415 with confidence than 425+ on a guess.

The one category nothing this session touched

Cross-lender + multi-filter (n=9) is both the lowest-scoring category in the baseline (3.00/4, 27/36) and the one none of this session's six fixes were aimed at. Its three low scorers — CQ-042 (Resimac/Angle/BFS), CQ-043 (all-lender), CQ-103 (Metro/Resimac/Angle) — combine a named-lender-or-more scope with an extra filter condition on top, a shape distinct from anything diagnosed this session. Worth a dedicated look before relying on the full-111 number improving as much as this category could allow.
